# Branding

The app follows the current **refetch.io**. Every brand value below says where
it came from, so the next rebrand can start from the same sources.

Sources, read on 2026-11-08:

| Source | What it gave |
| --- | --- |
| `https://refetch.io/assets/app-*.css` (live) | Colour tokens for `:root` (light) and `.dark` |
| [`DESIGN.md`](https://github.com/refetch-io/refetch/blob/main/DESIGN.md) in refetch-io/refetch | Principles, type scale, radii, logo rules, copy rules |

## Logo

- **Mark:** the circle with two arrows, `#4E1CB3` with white arrows, the same
  in every theme. Paths copied verbatim from the site's header SVG into
  `assets/brand/logo-mark.svg` and `assets/brand/logo-wordmark.svg`.
- **Wordmark:** `--logo-wordmark` on the live site: `#1D1D1F` light, `#FFFFFF`
  dark. The wordmark SVG uses `currentColor`, which `RefetchLogo`
  (`lib/core/widgets/refetch_logo.dart`) sets from the theme.
- **Not on purple.** DESIGN.md: "don't place the logo on purple backgrounds".
  So the launcher icon is the purple mark on white, like the site's own
  `maskable-512.png` and `apple-touch-icon.png`, replacing the old white arrows
  on `#5A00FF`.

> Note: DESIGN.md says the light wordmark is `#4e1cb3`, but the live CSS sets
> `--logo-wordmark: #1d1d1f` for light mode. The app follows the live site.
> The site's `og.png` and `favicon.png` also still use the old style (logo on
> purple, and `#5A00FF` in the favicon); the app follows DESIGN.md and the new
> PWA icons instead.

## Type

DESIGN.md › Typography and the live CSS `--font-display` / `--font-sans`:

- **Titles: Poppins** 600/700, the wordmark's typeface (`assets/fonts/Poppins-*.ttf`,
  from google/fonts, OFL).
- **Body: Inter** 400/500/600/700 on Android, Windows and Linux
  (`assets/fonts/Inter-*.ttf`, Inter 4.1 from rsms/inter, OFL). On iOS and
  macOS the app uses the system font, as the site does through `-apple-system`.
- The scale (large-title 34 … footnote 13) maps onto Material's `TextTheme` in
  `AppTheme._textTheme`. Counters use tabular figures.
- Both licences are registered with `LicenseRegistry` (`lib/main.dart`).

## Shape and iconography

- Card radius 20 (`rounded-card`), control radius 12 (`rounded-control`),
  pill buttons (`rounded-full`).
- Stories sit in one rounded grouped list with inset hairlines (DESIGN.md:
  "Grouped, not boxed"); ranks on Top and Show, the first three in brand.
- Icons: **Lucide**, as on the site (`lucide_icons_flutter`).

## Voice

DESIGN.md › Copy: short plain sentences, no em dashes in the interface. Empty
states follow the site's pattern: icon, one-line title, one sentence, at most
one action. AI summaries are labelled in words ("Summary, generated by AI").
Tagline: "The front page for builders" (manifest and page title).

## Regenerating the art

```bash
pip install resvg_py pillow
python tool/render_brand_assets.py      # icon, adaptive/monochrome, splash, Play icon + feature graphic
dart run flutter_launcher_icons         # platform launcher icons
dart run flutter_native_splash:create   # launch screens
```

`flutter_launcher_icons` 0.14.4 rewrites
`ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS` in
`ios/Runner.xcodeproj/project.pbxproj` to `AppIcon`; revert that hunk.

Store screenshots in `android/fastlane/metadata/android/en-US/images/phoneScreenshots/`
are taken from the running app on a phone (1080x2340).
